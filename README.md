# Quickbox Upload

> 上传文件到 QuickBox (快取柜) 并获取临时分享链接。使用场景：(1) 需要临时分享文件给他人，(2) 文件中转传输，(3) 生成可下载的临时链接。当用户提到上传文件到快取柜、生成临时文件链接、分享文件、临时文件存储时使用此技能。

## 安装

将本仓库放到 OpenClaw 技能目录即可使用：

```bash
git clone <本仓库地址> ~/.openclaw/workspace/skills/quickbox-upload-skill
# 或放入 ~/.openclaw/skills/
```

## 配置

如需 API Key、邮箱授权码等配置，请参考 `SKILL.md` 中的说明，通过环境变量或本地 `.env` 文件设置（**不要提交到仓库**）。

详见 [SKILL.md](./SKILL.md)。
